DingDone｜Windows 64 位便携版

第一次使用

1. 不要直接在 ZIP 压缩包里双击文件。
2. 右键 ZIP，选择“全部解压”。
3. 打开解压后得到的完整文件夹。
4. 双击 Start-DingDone.cmd。
5. 稍等片刻，浏览器会自动打开 DingDone。

如果打不开

- 启动窗口会直接显示原因，请先截取这个窗口。
- 诊断日志位于：
  %LOCALAPPDATA%\DingTalkReminderManager\logs\startup.log
- 请把截图和 startup.log 发给维护者。

开始使用

1. 在“机器人管理”中添加自己的钉钉机器人 Webhook。
2. 先执行测试发送，确认目标群正确。
3. 测试成功后再创建提醒，并开启真实定时发送。

登录自动运行与异常恢复

- 双击 Enable-AutoStart.cmd：开启登录自动运行和异常自动恢复。开启后不要移动或删除整个程序文件夹。
- 双击 Disable-AutoStart.cmd：取消登录自动运行和异常恢复；当前已运行的后台不会因此停止。
- 双击 Stop-DingDone.cmd：停止本次 Windows 登录期间的后台和守护；如果自动运行仍开启，下次登录会恢复。

重要说明

- 页面关闭后，后台仍会运行。
- 电脑必须开机、联网并保持 Windows 用户登录，才能按时发送。
- 每位用户的数据只保存在自己的 Windows 用户目录。
- 分发包不包含制作者的机器人、Webhook、提醒任务或发送历史。
- 首次启动会载入预设内容池、三套话术池和星期规则。
- Webhook 和加签密钥使用当前 Windows 用户加密保护。
- 更新到新版时，原有机器人、提醒和记录仍保存在用户目录，不会被新版模板覆盖。
- 同一个群的相同提醒不要在两台电脑同时启用，以免重复发送。
